# v0.2.0 — SystemInfo works, PCMark 10, everything automatic

**3DMark 11 now starts under Proton** — the first time UL SystemInfo works on Linux — and 3DMark shows your CPU and GPU.

## Highlights

- **PCMark 10** support next to 3DMark and 3DMark 11; whatever your Steam account owns is installed and configured.
- **UL SystemInfo fixed under Proton**: COM classes mirrored to the 64-bit registry view, RpcSs auto-start, win64 typelib, and a launch wrapper so Steam doesn't show the app as running after you close it.
- **Proton Experimental by default** — Steel Nomad now runs (541 on Intel Arc 140T) and Time Spy scores ~10 % higher than on Proton 10.
- **All 3DMark tests downloaded in one go** (`tests`), no clicking through the app.
- **CD keys fetched automatically** from Steam (X11: fully automatic; Wayland: one click) and verified.
- **KDE Plasma and LXQt**: real title bars via KWin / Openbox / labwc rules (`titlebar`).
- No more protontricks: the Wine registry is edited directly and d3dcompiler_47 is installed from the same checksummed source winetricks uses.
- CI: shellcheck, shfmt, ruff, yamllint, pymarkdown, actionlint, unit + end-to-end tests (fake Steam install), reproducible release tarball with SHA256SUMS.

## Install

```bash
curl -LO https://github.com/ventura8/linux-steam-3dmark-helper/releases/download/v0.2.0/linux-steam-3dmark-helper-0.2.0.tar.gz
sha256sum -c --ignore-missing SHA256SUMS   # after downloading SHA256SUMS too
tar xzf linux-steam-3dmark-helper-0.2.0.tar.gz && cd linux-steam-3dmark-helper-0.2.0 && ./3dmark-helper.sh
```

You need your own copy of [3DMark](https://store.steampowered.com/app/223850/3DMark/), [3DMark 11](https://store.steampowered.com/app/205270/3DMark_11/) or [PCMark 10](https://store.steampowered.com/app/524390/PCMark_10/). Unofficial project, not affiliated with UL Solutions or Valve.
